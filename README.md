# DevTrack 🚀

**A developer productivity dashboard built with Flutter.**

DevTrack is a mobile application designed to help developers organize projects, monitor tasks, and visualize development progress from one place.

## ✨ Features

- 📊 **Dashboard** — Overview of projects, tasks, bugs, and productivity.
- 📁 **Project Overview** — View project descriptions, technologies, and progress.
- ✅ **Task Management UI** — Track sample tasks and completion status.
- 📈 **Analytics** — Visualize weekly activity with charts.
- 📱 **Responsive Interface** — Mobile-friendly layout with bottom navigation.
- ⚙️ **Settings Screen** — Application settings interface.

> Note: The current version uses sample data. Persistent storage, fully interactive task management, and live GitHub integration are planned improvements.

## 🛠️ Tech Stack

- Flutter
- Dart
- Material 3
- fl_chart

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Android Studio or VS Code
- Android emulator or physical Android device

### Installation

Clone the repository:

```bash
git clone https://github.com/lokeshyadavyadav9172-coder/devtrack-flutter.git
cd devtrack-flutter
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

## 🧪 Testing

Run static analysis:

```bash
flutter analyze
```

Run tests:

```bash
flutter test
```

## 📦 Android APK

Build a release APK:

```bash
flutter build apk --release
```

The APK will be generated at:

`build/app/outputs/flutter-apk/app-release.apk`
